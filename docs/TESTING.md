# 検証の実行方法

```sh
uv sync --locked
uv run pytest -q
cd frontend
pnpm install --frozen-lockfile
pnpm build
pnpm test:diff
pnpm test:ai
pnpm test:alignment
pnpm test:pdf
pnpm exec playwright install --with-deps chromium
pnpm test:e2e
```

クラウドAIを呼ぶテストはありません。バックエンドのAI応答はモックです。
EPUBCheck統合テストはJavaとscripts/install_epubcheck.pyで導入したJARがある場合に実行します。
GitHub Actionsにはバックエンド、ブラウザー、Docker起動・データ保持の検証を設定しています。

開発Macでの独立Chromium起動には制限があり、Playwright全体は未完走です。
Docker daemonとComposeも使えないため、コンテナ起動はGitHub ActionsまたはDebian環境で確認してください。
ブラウザーUIは独立した検証データで確認しています。iPad実機でのピンチ操作は未確認です。
